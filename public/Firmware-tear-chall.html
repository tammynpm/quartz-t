At first, i used the binwalk command to see if there is any files embedded in the firmware. There was. 

This shows that the firmware has SquashFS as file system. The next step is how to extract this file system from the firmware. Normally, I would use the command binwalk -e to extract it. But there was an error when using that command. 

A possible reason why -e flag doesn’t work is because binwalk was installed with version 3+ which used Rust. 

Another approach is to extract the file system out of the firmware. To do this, we can use the dd linux built-in command

From the output of binwalk, we know the offset is at byte 1048576 and the size of the file system is 4931098 bytes. 

dd if=firmware of=squashfs.sqsh bs=1 skip=1048576 count=4931098

We have the output file as the archive of the file system: 

file squashfs.sqsh 

squashfs.sqsh: Squashfs filesystem, little endian, version 4.0, zlib compressed, 4931098 bytes, 24 inodes, blocksize: 131072 bytes, created: Sun Jul 14 18:29:46 2024

we have to “unsquash” this

From here, there are two ways to read the file: mount the file system, or extract the files.
