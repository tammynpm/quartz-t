aka code division multiplesxing (CDM) 
use case: modern cellular networks -> numerous users to converse at once without cross talk 

- allows multiple signals to share the same frequency spectrum simultaneously 
- assigning a unique code -> each signal -> signals are transmitted sequentially without interference. 

- orthogonal codes -> ensure sgnals to be separated and decoded correctly at the receiver end
