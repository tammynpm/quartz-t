## lsa (link-state advertisement)

- ospf message used to share network topology, link states + routing info --> routers can build identical maps of an area

- are carreid in link state update packets (LSU) wiht type 1 (router), type 2 (network) 


5 LSA types in OSPF:
- router LSA: generated by all routers to describe interface status, ip addresses, cost to neighbors within a single area
- network lsa: created by Designated router in multi-access networks (like ethernet) to list all routers attached to segment, keeping it within the local area
- summary lsa: generated by area border routers --> advertise networks from 1 area to another, summarizing topology to improve scalability
- ASBR summary: generated by ABRs to 




### transit network vs stub network

- trnasit: network lsa; shared by multiple routers
- stub: router lsa: connected to only 1 router


### lsdb --> routing table 

core of ospf: lsdb --> full topology --> run spf (dijkstra) --> install routes
